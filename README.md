# 🎯 Smart Resume Screener

An AI-powered web app that ranks job candidates by analyzing resumes against a job description using Groq's LLaMA3 AI model.

## 🔗 Live Demo
👉 https://resume-screener-nmed.onrender.com

## 🚀 Features
- Upload multiple PDF resumes at once
- AI scores each candidate out of 100
- Shows strengths, gaps, and summary for each candidate
- Ranks candidates from best to worst fit

## 🛠️ Tech Stack
- Python, Flask
- Groq API (LLaMA3)
- pdfplumber
- HTML, CSS, JavaScript
